# 🏷 Project Name

A page, initially designed with figma but replicated using just HTML and CSS

## 📌 Problem Statement

Many developers have lost their touch in styling sites and making it responsive to different screen sizes. This project helped me understand what each CSS property does and how to make a page responsive to all screen sizes.

## 🎯 Project Goals

🧠 Challenges Faced

- I started my design from the desktop view. Making the mobile responsive was tideous and lots of lines
- I didn't really under the whole responsive concept well so i failed alot in the process.
- I didn't implement know to use the flex and grid property properly . Had to learn

📚 What I Learned

- If i make good use of div and separate the sections properly, styling and responsive will be easier
- Using % in the widths and height makes it easier for the page to be responsive rather than using px and rem

Future Improvements

- I'll structure my HTML sheet better so it has fewer lines of code
- I'll make use of grid and flex properties more often to make responsiveness easier.
